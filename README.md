
# 🎓 Öğrenci Not Hesaplama Uygulaması

HTML, CSS ve JavaScript kullanarak geliştirdiğim
basit bir öğrenci not hesaplama uygulamasıdır.

## Özellikler

- Vize ve final notlarını girme
- Vize %40, final %60 ağırlığıyla ortalama hesaplama
- Ortalama 50 ve üzerindeyse "Geçtin" sonucu gösterme
- Ortalama 50'nin altındaysa "Kaldın" sonucu gösterme
- Boş veya geçersiz notlar için uyarı verme
- Mobil uyumlu tasarım

## Kullanılan Teknolojiler

- HTML
- CSS
- JavaScript

## Nasıl Kullanılır?

1. Vize notunu girin.
2. Final notunu girin.
3. "Ortalamayı Hesapla" butonuna tıklayın.
4. Ortalama ve geçme durumunu görüntüleyin.

Not: Geçme sınırı örnek olarak 50 alınmıştır.
